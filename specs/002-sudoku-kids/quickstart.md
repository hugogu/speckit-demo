# Quickstart: Sudoku for Kids

This guide helps you set up the development environment for the Sudoku for Kids feature.

## Prerequisites

- Node.js v18 or higher
- npm v9 or higher

## Setup

1. Clone the repository: `git clone https://github.com/hugogu/speckit-demo.git`
2. Switch to the feature branch: `git checkout 002-sudoku-kids`
3. Install dependencies: `npm install`

## Running the development server

`npm start`

## Building for production

`npm run build`

## Running tests

`npm test`
